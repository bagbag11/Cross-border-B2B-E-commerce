# 审查比对规则

## 路线层面比对

### 路线数核对
- 源文件路线数 vs DB 路线数（按货代名称筛选）
- 若 DB 路线数远超源文件：检查是否用错了源 sheet（如按邮编×仓库拆分的细粒度表 vs 按目的港汇总的路线表）
- 若 DB 路线数少于源文件：检查是否有遗漏未导入的路线

### 路线字段逐项比对
| 字段 | 比对方式 |
|---|---|
| 线路名称 | 源文件目的港产品+服务区域拼接 |
| 货代名称 | 源文件标题/表头 |
| 渠道类型 | 空运=air / 海运=sea / 陆运=land / 铁路=land |
| 计费方式 | 源文件备注中提取（体积重与实重取大计费 / 实重计费 / 体积计费） |
| 报价币种 | RMB / USD |
| 支持邮编范围 | 源文件服务区域列原文 |
| 覆盖城市 | 从目的港或邮编推断 |
| 最小/最大物流时效 | 源文件"参考时效"列，"X天左右"取整 |
| 最长边限制 | 源文件尺寸说明（cm） |
| 运输类型 | 干线+尾程派送 / 仅干线 / 门到门 等 |
| 是否尾程派送到门 | 卡车派送→是 / 仓库自提→否 |
| 是否启用 | 有源→启用 / 无源→停用 |
| 服务类型 | 自行卸货/快递柜/等（源文件未提及则留空） |
| 清关模式 | 双清包税/不包税/单清等（源文件未提及则留空） |

## 价格层面比对

### 单价回源
每条路线的每档单价，逐一与源文件对应行/列比对：
- **完全一致**：✅ 正确
- **价格存在但分配到错误路线**：系统性错位（P0）
- **价格在源文件中完全不存在**：虚假价格（P0，需删除）
- **近似值（四舍五入差异）**：标记但非编造，按用户指示处理

### 价格结构核对
| rule_type | 结构 | 核对点 |
|---|---|---|
| unit_price | 单价 × 计费单位 | 单价值、计费单位、重量档位边界 |
| range_price | 区间价 | 区间边界、区间内单价 |
| first_continued | 首续重 | 首重重量+价格、续重单位+价格 |

### 重量档位核对
常见 7 档：101-150 / 151-300 / 301-500 / 501-1000 / 1001-2000 / 2001-3000 / 3001+
- 注意源文件表头写"1001+"时，下一档起算为 2001（不是 1002）
- 档位边界值（最小重量限制/最大重量限制）必须与源文件一致

## 附加费用核对

| 字段 | 来源 | 常见缺失原因 |
|---|---|---|
| 最低收费 | 派送费/票（如 500 元/票） | 导入时未提取备注信息 |
| 超长附加费 | 源文件附加费说明 | 文字描述未结构化 |
| 超长条件 | 触发超长费的长度阈值（如 ≥300cm） | 同上 |
| 最大长度限制 | 拒收上限（如 800cm） | 同上 |
| 超重条件 | 单件重量/尺寸拒收规则 | 同上 |
| 报关费 | 单独报关费+续页费等 | 导入时未提取 |
| 木箱/木架包装单价 | 包装费用表 | 独立 sheet 未关联 |

## 尺寸限制核对

源文件尺寸表述形式多样，需按渠道逐组核对：
- **单一限制**："最长边≦200cm" → 最长边限制=200
- **围长公式**："长+2×宽+2×高≦350cm" → 围长限制=350
- **三边和**："三边之和不超120CM" → 三边之和限制=120
- **拒收上限 vs 附加费触发点**：附加费触发点（如"超2M+100元"）不是拒收上限，不应填入限制字段
- **多档尺寸表**：如加拿大 UPS 有超长超重费用表，取最高档作为限制值

## 重复路线判定

**标准**：同一行全部字段完全相同才算重复。
- 邮编不同 = 合理展开，不算重复
- 路线名称相同但邮编/仓库不同 = 不同路线
- 仅当所有字段（含邮编、仓库、价格）完全一致时才判定为重复
